# Кейс-бот (aiogram + Telegram Mini App)

Бот выдаёт стартовый баланс виртуальных монет и открывает мини-апп с одним
кейсом — рулеткой из 6 предметов разной редкости. Открытие кейса стоит
монеты, результат считается на сервере и зачисляется в баланс.

## Структура

```
case_bot/
├── main.py         # запуск бота + API-сервера
├── server.py        # aiohttp: раздаёт мини-апп и API (/api/me, /api/spin)
├── auth.py           # проверка подписи Telegram.WebApp.initData
├── db.py              # SQLite-хранилище балансов
├── items.py            # содержимое кейса и вероятности
├── config.py            # токен, URL мини-аппа, игровые константы
└── webapp/static/        # HTML/CSS/JS мини-аппа
```

## Установка

```bash
cd case_bot
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Задай переменные окружения:

```bash
export BOT_TOKEN="твой_токен"
export WEBAPP_URL="https://твой-домен-или-ngrok-адрес"
export PORT=8080
```

**Важно:** Telegram Mini App открывается только по HTTPS. `http://localhost`
не сработает даже для локальных тестов.

### Локальный тест через ngrok

```bash
# в одном терминале — сервер
python main.py

# в другом терминале — туннель к порту 8080
ngrok http 8080
```

Скопируй HTTPS-адрес, который выдал ngrok (например
`https://abcd1234.ngrok-free.app`), пропиши его в `WEBAPP_URL` и перезапусти
`main.py`.

### Прод

Задеплой на любой хостинг с постоянным HTTPS-адресом (VPS + Nginx/Caddy,
Railway, Render и т.п.), пропиши реальный домен в `WEBAPP_URL`.

## Запуск

```bash
python main.py
```

Бот и API-сервер стартуют вместе в одном процессе. Напиши боту `/start` —
придёт кнопка «Открыть кейс», которая откроет мини-апп.

## Что можно докрутить дальше

- Несколько разных кейсов вместо одного.
- Магазин: покупка монет за Telegram Stars (`invoice`) вместо бесконечного
  бесплатного баланса.
- Инвентарь предметов вместо мгновенного обмена на монеты.
- Таблица лидеров, ежедневный бонус, реферальная система.
- Переезд с SQLite на PostgreSQL при росте нагрузки.

## О виртуальной валюте

Экономика в этом проекте полностью виртуальная и учебная: монеты нельзя
купить или обналичить. Если планируешь монетизацию через реальные деньги —
уточни у меня, это отдельная история с юридическими и платформенными
ограничениями (правила Telegram, законы о лутбоксах/азартных играх
отличаются по странам).
